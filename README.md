# Proyecto PAEC - Composta

Plataforma web desarrollada en Django para la gestión, seguimiento y difusión del proyecto comunitario de composta (PAEC).

## Tecnologías utilizadas
- **Backend:** Python, Django
- **Frontend:** HTML5, CSS3
- **Base de datos:** SQLite3
